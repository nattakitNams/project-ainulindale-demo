```
เบราว์เซอร์ผู้ใช้
  │  เปิด  https://<เว็บที่ deploy>/        ← โฟลเดอร์ web/ (ไฟล์นิ่งล้วน: html/js/css)
  │
  │  fetch() + โทเคนจับคู่
  ▼

ไฟล์ข้อมูล · CPU · RAM ของเครื่องนั้น (ไม่มีอะไรถูกอัปโหลดขึ้นเว็บ)
```

## โครงสร้าง
| ส่วน | ที่อยู่ | หมายเหตุ |
|---|---|---|
| หน้าเว็บ (deploy ได้ทั้งโฟลเดอร์) | `web/` | path แบบสัมพัทธ์ วางใต้ path ย่อยได้ (เช่น `user.github.io/ainulindale/`) |
| ตัวเชื่อมต่อ/จับคู่ | `web/config.js` | ที่อยู่ตัวประมวลผล · แนบโทเคนทุก fetch · หน้าจอ "ยังไม่ได้เชื่อมต่อ/ยังไม่ได้จับคู่" |
| ตัวประมวลผล | `app/` | โค้ดเดิม + ด่านความปลอดภัยใน `server.py` (`_guard`, `_cors`, `/api/engine/hello`) |
| ตั้งค่าเว็บที่อนุญาต | `engine.json` | `allowed_origins` + `web_url` (หน้าที่จะเปิดพร้อมลิงก์จับคู่) |
| workspace | `workspace/` | แยกจาก v0.5 · คัดลอกเฉพาะ `catalog.db`, `secrets.json` (ชี้ไปไฟล์ข้อมูลเดิม) · โทเคนอยู่ที่ `engine_token.txt` |

## รัน (ทดสอบในเครื่อง)
1. `start_engine.bat` → ตัวประมวลผลที่พอร์ต 41217 แล้วเปิดลิงก์จับคู่ให้เอง
2. `serve_web_dev.bat` → จำลองเว็บที่ deploy แล้วที่ `http://127.0.0.1:8090` (คนละ origin)
3. ไม่มีเน็ต/ไม่อยากใช้เว็บ: เปิด `http://127.0.0.1:41217/ui/` (หน้าสำรองจากตัวประมวลผล ไม่ต้องจับคู่)

v0.5 (พอร์ต 5100) กับ v1 (พอร์ต 41217) รันพร้อมกันได้

## ความปลอดภัย (สำคัญ เพราะเปิดให้เว็บภายนอกเรียกเครื่องผู้ใช้)
1. **Host ต้องเป็น 127.0.0.1/localhost** → กัน DNS rebinding
2. **Origin ต้องอยู่ใน `allowed_origins`** (หรือเป็นหน้าของตัวประมวลผลเอง) → เว็บอื่นอ่านข้อมูลไม่ได้ (403)
3. **คำขอที่เปลี่ยนข้อมูล (POST/PATCH/DELETE) ต้องมีโทเคนจับคู่** `X-Ainu-Token` → 401 ถ้าไม่มี/ผิด
4. ตอบ preflight ของ **Private Network Access** (`Access-Control-Allow-Private-Network: true`) — Chrome/Edge รุ่นใหม่จะถามผู้ใช้ "อนุญาตให้เว็บนี้เข้าถึงอุปกรณ์ในเครือข่าย" ครั้งแรก
5. โทเคนส่งผ่าน `#fragment` ของลิงก์ (ไม่ถูกส่งไปเซิร์ฟเวอร์ของเว็บ) แล้วลบออกจากแถบที่อยู่ทันที

ทดสอบแล้ว 12 กรณี: เว็บแปลกหน้า → 403 · ไม่มีโทเคน → 401 · โทเคนผิด → 401 · Host ปลอม → 403 · preflight → 204 + PNA ✔

## ข้อจำกัดของต้นแบบ
- GET ที่ไม่ส่ง Origin (เช่น `<img>` ไทล์) ยังผ่านได้โดยไม่มีโทเคน — เว็บอื่น "แสดง" ภาพไทล์ได้แต่อ่านค่าไม่ได้ ควรเพิ่มโทเคนใน URL ภาพก่อนใช้จริง
- ข้อมูลในเบราว์เซอร์ (ชั้นแผนที่ซ้อน, การจัดหน้ารายงาน) เก็บแยกตาม origin → เปลี่ยนที่อยู่เว็บแล้วต้องตั้งใหม่ (ย้ายไปเก็บที่ตัวประมวลผลได้)
- ฟอนต์/Leaflet โหลดจาก CDN — หน้าเว็บต้องมีเน็ต (หน้าสำรอง /ui/ ก็เช่นกัน ยกเว้นจะรวมไฟล์ไว้ในเครื่อง)
- ยังต้องมี Python + ไลบรารีในเครื่อง (ยังไม่ได้แพ็กเป็นตัวติดตั้ง)
