def ext_from_view(v, w, h):          # w, h = ขนาดกรอบ (มม.)
    k  = math.cos(math.radians(v['cy']))
    dh = float(v['span'])
    dw = dh * (w / h) / k
    return [v['cx'] - dw/2, v['cy'] - dh/2, v['cx'] + dw/2, v['cy'] + dh/2]

06report.js — คณิตศาสตร์ของสิ่งที่วาดทับแผนที่

ภาพแผนที่เป็นละติจูด/ลองจิจูดแบบเชิงเส้นเต็มกล่อง → แปลงพิกัดเป็นตำแหน่ง มม. ได้ด้วยสมการเส้นตรง

กริดพิกัด · ป้ายชื่อ · มาตราส่วน

X(ลอง) = (ลอง − x0) ÷ (x1 − x0) × กว้างมม.
Y(ละติ) = (y1 − ละติ) ÷ (y1 − y0) × สูงมม.

ระยะกริด: เลือกจาก [1′, 2′, 5′, 10′, 15′, 0.5°, 1°, 2°, 5°, 10°…] ตัวแรกที่ทำให้ได้ ≤ 5 เส้น · ต่ำกว่า 1° แสดงเป็นลิปดา เช่น 100°30′E

กม./มม. = Δลอง × 111.32 × cos(ละติจูดกลาง) ÷ กว้างมม.
มาตราส่วน 1 : (กม./มม. × 10⁶) → ปัด 2 หลัก

ความยาวแท่ง = ค่าสวยตัวใหญ่สุด (1, 2, 2.5, 5 × 10ⁿ) ที่ไม่เกิน 85% ของกล่อง · ต่ำกว่า 1 กม. เปลี่ยนเป็นเมตร

ป้ายชื่อไม่ทับกัน (declutter)

เก็บ ภาพรวมทั้ง doc เป็นข้อความ JSON หลังทุกการแก้ (สูงสุด 100 ครั้ง) — ง่ายและไม่พลาด แม้การแก้ซับซ้อนอย่างเปลี่ยนเทมเพลต · ตอนย้อนกลับ ขอภาพใหม่เฉพาะกรอบที่ขนาด/มุมมองเปลี่ยน

const commit = () => {
  const s = JSON.stringify(doc);
  if (s === last) return;
  hist.push(last); fut = []; last = s;
  save();                 // localStorage
};

// ลากไป dx, dy มม. → เลื่อนจุดกลางในทิศตรงข้าม (เป็นองศา)
vw.cx -= dx * (ext[2] - ext[0]) / e.w;
vw.cy += dy * (ext[3] - ext[1]) / e.h;
// ล้อเมาส์ → ย่อ/ขยายความสูงของมุมมอง
e.p.view.span *= ev.deltaY > 0 ? 1.15 : 1 / 1.15;

บั๊กที่เจอระหว่างทำ (และสาเหตุ)

จุดจับย่อขยายกดไม่ได้องค์ประกอบมี z-index 10+ แต่หน้ากระดาษไม่ได้แยกชั้น → จุดจับจมอยู่ข้างใต้ · แก้: #rpPage { z-index: 0 }
ดับเบิลคลิกแก้ข้อความไม่ติดsetPointerCapture ทำให้ dblclick เกิดที่ stage · แก้: elementsFromPoint()
การ์ดตัวเลขเรียงผิดคลาสของกล่อง rpt-kpi ซ้ำกับเนื้อใน · แก้: rpt-t-<type>
ข้อความท้ายหน้าหายเงียบjustify-content:flex-end ทำให้ส่วนล้นหลุดด้านบน วัดไม่ได้ · แก้เป็น margin-top:auto + เตือน "⚠ ล้น"
