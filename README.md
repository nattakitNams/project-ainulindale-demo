# Ainulindalë — Bivariate map studio

เครื่องมือไขว้ข้อมูลภูมิสารสนเทศสองชุดเป็น **แผนที่ไบแวเรียต** (เช่น ประชากร × พื้นที่น้ำท่วม) สำหรับข้อมูลใดก็ได้
ทั้งราสเตอร์และเวกเตอร์ ความละเอียดต่างกันได้ ผลรวมค่าไม่หาย (count / density / class มีกติกาการรวม-แตกพิกเซลต่างกัน)
พร้อมแปลงเวกเตอร์ ↔ ราสเตอร์ ↔ หกเหลี่ยม (hex), เปรียบเทียบ 2 ช่วงเวลา, แผนที่ซ้อนชั้น, คลังข้อมูลแบบโฟลเดอร์ + ถังขยะ,
Data hub รายชื่อแหล่งข้อมูล ~1,560 ชุด และตัวออกแบบรายงานแผนที่แบบลากวาง (ส่งออก PDF) · หน้าเว็บสองภาษา ไทย / English

**หน้าเว็บ:** https://nattakitnams.github.io/project-ainulindale-demo/

## ทำงานอย่างไร — หน้าเว็บบนเน็ต + ประมวลผลในเครื่องคุณ

```
เบราว์เซอร์  ──▶  หน้าเว็บ (GitHub Pages: โฟลเดอร์ web/ ไฟล์นิ่งล้วน)
     │
     │  fetch() + โทเคนจับคู่
     ▼
http://127.0.0.1:41217  ──▶  ตัวประมวลผล Python (โฟลเดอร์ app/) ในเครื่องคุณ
                              rasterio/GDAL · NumPy · หลายเธรด · Edge พิมพ์ PDF
```

- **ไฟล์ข้อมูลไม่ถูกอัปโหลด** — การคำนวณทั้งหมดใช้ CPU / RAM / ดิสก์ของเครื่องคุณ
- ตัวประมวลผลรับคำสั่งเฉพาะจาก 127.0.0.1 และหน้าเว็บในรายชื่อที่อนุญาต (`engine.json`) · คำสั่งที่เปลี่ยนข้อมูลต้องมีโทเคนจับคู่
- สิ่งที่ออกอินเทอร์เน็ต: ภาพแผนที่พื้นหลัง (Esri / OpenStreetMap / Google), ฟอนต์ (Google Fonts), บริการแผนที่ที่ผู้ใช้เพิ่มเอง

## ติดตั้ง (Windows 10/11 · ไม่ต้องใช้สิทธิ์ admin)

1. ดาวน์โหลด `Ainulindale-setup.zip` จาก [Releases](https://github.com/nattakitNams/project-ainulindale-demo/releases/latest)
2. แตกไฟล์ไว้ที่ไหนก็ได้ — ทุกอย่างของแอปจะอยู่ในโฟลเดอร์นี้
3. ดับเบิลคลิก `Ainulindale.bat` → หน้าเว็บเปิดตัวช่วยติดตั้ง (ดาวน์โหลดแพ็กเกจ ~180 MB จาก PyPI ครั้งแรกครั้งเดียว ตรวจ SHA-256 ทุกไฟล์)

Windows อาจเตือน "Windows protected your PC" เพราะไฟล์ยังไม่ได้ลงนามดิจิทัล → **More info → Run anyway**
ถอนการติดตั้ง: รัน `uninstall.bat` หรือลบโฟลเดอร์ทิ้ง

# สำหรับนักพัฒนา

ประวัติการพัฒนา บักที่เคยเจอและวิธีแก้ อยู่ใน `DEVLOG.md` (ไฟล์ในเครื่องผู้พัฒนา ไม่อยู่ใน repo สาธารณะ)

## 1. สถาปัตยกรรม — หน้าเว็บบนเน็ต + ประมวลผลในเครื่องผู้ใช้

```
เบราว์เซอร์ ──▶ หน้าเว็บ (GitHub Pages: โฟลเดอร์ web/ — HTML/JS/CSS นิ่งล้วน ไม่มี build step)
    │  fetch() + โทเคนจับคู่ (header X-Ainu-Token)
    ▼
http://127.0.0.1:41217 ──▶ ตัวประมวลผล Flask (app/) ในเครื่องผู้ใช้
    │   งานหนักรันใน process แยก (app/worker.py) ทีละงาน
    ▼
ไฟล์ข้อมูล · CPU · RAM ของเครื่องนั้น — ไฟล์ข้อมูลไม่ถูกอัปโหลดไปไหน
```

- **หน้าเว็บสำรอง** `http://127.0.0.1:41217/ui/` = โฟลเดอร์ `web/` เดียวกัน เสิร์ฟโดยตัวประมวลผลเอง (same-origin ไม่ต้องจับคู่)
- **ความปลอดภัย** (`app/server.py`: `_guard`, `_cors`) — เปิดให้เว็บภายนอกสั่งเครื่องผู้ใช้ จึงต้องเข้ม:
  1. Host ต้องเป็น `127.0.0.1` / `localhost` (กัน DNS rebinding)
  2. Origin ต้องอยู่ใน `engine.json → allowed_origins` หรือเป็นหน้าของตัวประมวลผลเอง
  3. คำขอที่เปลี่ยนข้อมูล (POST/PATCH/DELETE) ต้องมีโทเคนจับคู่ (`engine_token.txt` — **ห้ามขึ้น git**)
  4. ตอบ preflight ของ Private Network Access · ฝั่งเว็บส่ง `targetAddressSpace: 'loopback'` (Chrome Local Network Access)
  5. โทเคนส่งผ่าน `#pair=` ของลิงก์ (ไม่ถึงเซิร์ฟเวอร์เว็บ) แล้วลบออกจากแถบที่อยู่
- **ตัวติดตั้ง** (`Ainulindale-setup.zip` สร้างโดย GitHub Actions): Python 3.13 แบบพกพา + `app/setup_server.py` (ไลบรารีมาตรฐานล้วน)
  เปิดหน้าเว็บตัวช่วยติดตั้ง → ติดตั้งแพ็กเกจจาก PyPI ด้วย `--require-hashes` (ไฟล์ล็อก SHA-256) → ส่งพอร์ตต่อให้ตัวประมวลผลจริง
  (`app/launch.py` = จุดเริ่ม: ติดตั้งแล้ว → server · ยังไม่ติดตั้ง → setup_server)

## 2. เริ่มพัฒนาในเครื่อง

ต้องมี Windows + Python 3.13 + แพ็กเกจตาม `installer/requirements.in`

```bat
pip install -r installer/requirements.in
start_engine.bat                         :: ตัวประมวลผลที่พอร์ต 41217 แล้วเปิดลิงก์จับคู่ให้เอง
serve_web_dev.bat                        :: จำลองหน้าเว็บที่ deploy ที่ http://127.0.0.1:8090 (คนละ origin)
```

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `AINU_PORT` | พอร์ตตัวประมวลผล (ค่าเริ่มต้น 41217) |
| `AINU_WORKSPACE` | โฟลเดอร์ทะเบียน/ผลลัพธ์/แคช (ค่าเริ่มต้น `settings.json` → `workspace/`) |
| `python -m app.server --no-browser` | ไม่เปิดเบราว์เซอร์ตอนเริ่ม |

**แนะนำมากที่สุด:** ทดสอบกับตัวประมวลผลแยก ไม่ใช้ workspace จริง
```bat
set AINU_PORT=41299
set AINU_WORKSPACE=D:\ainu_test_ws
python -m app.server --no-browser
```
แล้วเปิด `http://127.0.0.1:41299/ui/`

## 3. แนวคิดหลักที่ต้องเข้าใจก่อนแก้

### 3.1 ประเภทค่า (value type) — หัวใจของความถูกต้อง
ทุกชุดราสเตอร์ต้อง **ยืนยันประเภทค่า** ก่อนใช้คำนวณ เพราะกติกาการรวม/แตกพิกเซลต่างกัน และตั้งผิด = ผลผิดแต่ดูปกติ

| ประเภท | ตัวอย่าง | ลดความละเอียด (รวมพิกเซล) | เพิ่มความละเอียด (แตกพิกเซล) |
|---|---|---|---|
| `count` จำนวนนับ | คน/พิกเซล | ผลรวม (ผลรวมไม่หาย) | หารเท่ากัน ÷k² (เตือน "ความแม่นยำเทียม") |
| `density` ต่อเนื่อง | คน/ตร.กม., NDVI, แสงไฟ | เฉลี่ยถ่วงพื้นที่ | ทำซ้ำค่า |
| `class` ชั้น | land cover, ชั้นน้ำท่วม | เสียงข้างมาก (majority) | ทำซ้ำค่า |

แอปเดาให้ (`dsinfo.guess_value_type`: ชื่อไฟล์ก่อน แล้วชนิดตัวเลข) แต่ผู้ใช้ต้องกดยืนยัน

### 3.2 กริด (`app/engine.py`, `app/gridmath.py`)
- ความละเอียดเก็บเป็น **เศษส่วนแม่นยำ** `res_exact` — ข้อมูลพิกัดองศาใช้หน่วย **ฟิลิปดา (″)** ไม่ใช่องศา (เคยเป็นบั๊กมาแล้ว)
- `align()` หากริดร่วมของหลายชุด: มุมเริ่มต่างกันได้ · เส้นกริดตรงกัน → อ่านตรงพิกเซล · เหลื่อมเกิน `ALIGN_TOL` (1% ของพิกเซลต้นทาง) → โหมด `warp` (ถ่วงพื้นที่ `Wy·A·Wxᵀ`)
- `OnGrid` โหมด `same` / `up` (แตก ×k) / `down` (รวม k×k) / `warp`
- `lattice_grid()` สร้างกริดจากขอบเขตเวกเตอร์บนแลตทิซของ raster อ้างอิง (ใช้ตอนแปลงเวกเตอร์ → ราสเตอร์)
- `check_tiles()` กันงานที่ไทล์เดียวใหญ่เกินหน่วยความจำ (เช่น 15″ → 0.01″ = ×1500)
- **scale/offset ของแบนด์** (เช่น VIIRS int16 ×10, MODIS NDVI ×0.0001): `band_scale` / `unscale` — ทุกจุดที่อ่านค่าต้องคูณ ให้ค่าตรงกับ QGIS

### 3.3 งาน (job) — `app/jobs.py`, `app/worker.py`
- งานหนักรันใน **process แยกทีละงาน** (ปิดหน้าเว็บได้ งานยังทำต่อ · ยกเลิกได้ / บังคับหยุด)
- ทุกงานผ่าน `server.validate_job()` ก่อน (ประเมินขนาด + คำเตือน — หน้าเว็บโชว์ก่อนกดเริ่ม)
- ผลลัพธ์ลงโฟลเดอร์ใหม่ทุกครั้ง `workspace/{derived|maps}/<วันเวลา>_<งาน>_<ชื่อ>_<hash>` + `lineage.json` (ที่มา ค่าที่ตั้ง สถิติ เวลา)
- ลงทะเบียนผลด้วย `ops.register_output()` (ผลเข้าโฟลเดอร์คลังเดียวกับข้อมูลต้นทาง)

### 3.4 เตรียมข้อมูล (prepare)
เพิ่มราสเตอร์ → งาน `prepare` อัตโนมัติ: สถิติ, ค่าสุ่ม 200k (ควอนไทล์/ฮิสโทแกรม), ฮิสโทแกรมจำนวนเต็ม (นับครบหรือไม่นับเลย ≤ 4096 ค่า), สำเนาพรีวิวพร้อม overview
เปลี่ยนวิธีคำนวณสถิติ/พรีวิว → **ขึ้นเลข `preview_key` (`ops.py`)** ให้ทุกชุดเตรียมใหม่ครั้งเดียว
ผลที่ระบบสร้างเอง **ไม่ต้องรอ prepare**: เขียน raster ผ่าน `ops.OutWriter` แล้วสถิติ/ค่าสุ่มถูกนับระหว่าง `write()` → `register_output()` บันทึกให้ (งานใหม่ที่เขียน raster ควรใช้ `OutWriter` เสมอ ไม่งั้นจะเกิดงานอ่านไฟล์ซ้ำทั้งไฟล์)

### 3.5 สไตล์แผนที่ (`app/symbology.py`)
แบบ QGIS: paletted / pseudocolor / gray · ค่าเริ่มต้นตาม `data_profile` (ดัชนี → RdYlGn, night light → ขาวดำ, อื่นๆ → viridis)
ช่วงสีตัด 2–98% (`stretch`: ถ้าศูนย์กองเกิน 30% ใช้ 98% ของพิกเซลที่มีค่า) · ส่งออก `.qml` ให้ QGIS ได้
